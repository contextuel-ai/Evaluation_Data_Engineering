**URL Parsing Results**

<h1>Hugging Face Models (Most Standardized)</h1>

All HF models follow this pattern: https://huggingface.co/{namespace}/{model}

Examples: https://huggingface.co/meta-llama/Llama-3-70B, https://huggingface.co/mistralai/Mistral-7B-v0.1

The {namespace} component refers to the organization or user account. The {model} component refers to the specific model repository. 

Accessing this URL renders a README.md file. 

**API Metadata (JSON):** https://huggingface.co/api/models/{namespace}/{model}

**Inference API:** https://api-inference.huggingface.co/models/{namespace}/{model}

**Dataset:** https://huggingface.co/datasets/{namespace}/{dataset}

Example: https://huggingface.co/datasets/open-llm-leaderboard/open_llm_leaderboard


<h1>GitHub</h1>

Many models are hosted directly in GitHub repositories: https://github.com/{organization}/{repository}

Example: https://github.com/meta-llama/llama


<h1>Replicate</h1>

URL Structure: https://replicate.com/{owner}/{model}

Example: https://replicate.com/meta/meta-llama-3-70b-instruct

API Metadata: https://api.replicate.com/v1/models/{owner}/{model}


<h1>Ollama</h1>

URL Structure: https://ollama.com/library/{model}

Example: https://ollama.com/library/llama3

Model List: https://ollama.com/library


<h1>Kaggle</h1>

URL Structure: https://www.kaggle.com/models/{owner}/{model}

Example: https://www.kaggle.com/models/google/gemma

API: https://www.kaggle.com/api/v1/models


**Google Gemini Model List API**: https://ai.google.dev/models/gemini
